## 本次修改

- 沿用现有 HTML 和模块，新增 `experience.js` / `experience.css` 做首页与手机体验；日期、进度、任务和添加操作优先，详情、旧导入、日历与高级规则按需展开。
- 手机“今天 / 计划 / 进度 / 设置”四入口；“今天”会回到当天。旧路线、刷题、历史入口保留。
- AI 两入口、复制后的下一步、格式修复按钮、成功解析后收起原始输入；未另写解析器、排期器或数据模型。
- 原图片模块增加隐藏保留、替换/恢复默认清理、恢复快照保护和失败回滚；手机卡片默认收起，可独立设置和调整裁切。
- 短句改约 15 秒，增加暂停/继续/关闭及持久化；减少动态效果和页面隐藏时停止切换。
- 新增默认关闭的两种 Web Audio 音效、音量与试听；仅可信手动勾选成功保存后触发。
- 应用显示版本 2.4.0，最终资源缓存版本 `v2.4.3`。所有新增运行资源列入原 Service Worker 预缓存，不强制打断旧页面更新。

## 声音试听的实际范围

通过浏览器 UI 播放两种提示，并用产品同一合成函数经真实 `OfflineAudioContext` 渲染 44.1kHz PCM WAV。45% 音量的峰值分别约 0.0639、0.0682，未削波。样本仅保存在忽略上传的 `test-artifacts/task-audition.wav` 与 `all-audition.wav`。

当前代理工具明确不支持音频输入，不能听见系统扬声器或回传 WAV。因此**实际播放已验证，人耳听感/设备响度未验收**。不能据此宣称“听起来舒适”；请在设置中试听并按设备调整音量。

## 尚未实际验证

- 原生文件选择器：Edge ChatGPT 扩展未开启“允许访问文件 URL”，自动设置本地文件失败。未修改用户浏览器权限。浏览器内生成的合成文件验证了后续处理链，不能代替真实文件选择器验收。需用户自行在扩展详情开启该权限后再走自动上传，或手动选择图片。
- Android / iOS 真机、软键盘、安全区域实机、独立 PWA 安装窗口、本轮 `file://` 图片能力、不同浏览器的自动播放策略未实测。
- 操作系统“减少动态效果”切换和真实后台/锁屏场景未实际验收；实现使用相应 media query、`document.hidden`，不保证后台音频。
- 缺少 Web Locks 时只保证本窗口图片操作串行，未进行不同浏览器的同时上传压力测试；旧版无法确认来源的孤立图片采取保留策略。
