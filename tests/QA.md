## 明确的验收限制

- 已确认 Edge 发出 beforeinstallprompt 并显示可安装入口；没有替用户执行 Windows 系统安装。未验证实际安装后的 standalone 窗口，也未在真实 Android、iOS 或桌面 Chrome 中实测。
- 文件自动上传需要浏览器扩展的“允许访问文件 URL”权限，当前未开启。未扩大该权限；实际恢复通过新增的粘贴 JSON 入口验收，它与文件输入共用解析、预览和恢复逻辑。
- 自动化下载接口不支持 Blob，不能接收浏览器的原生下载事件。已通过生成的可见 JSON 内容验证并保存可解析的测试文件；页面同时保留原生下载链接和可复制 JSON。
- file:// 直开受自动化 URL 策略限制，未实测；原文件位置不变，使用普通脚本和相对资源路径，且对 file:// 明确跳过 PWA 注册。
- 未发布到实际 GitHub Pages。已完成子路径本机实测、资源检查和可发布静态目录。
