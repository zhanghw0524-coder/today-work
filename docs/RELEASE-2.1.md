# Today Work 2.1 使用说明

把计划，变成今天要做的事。

## 生成 AI 提示词

在“每日任务”点击“让 AI 帮我制定计划”，填写目标、执行天数、每日可投入分钟及其他要求，点击“生成提示词”→“复制给 AI”。自行发送到喜欢的 AI。Today Work 不连接 AI，不发送表单内容。

执行天数指实际安排任务的天数；例如 5 个执行日只在工作日执行，遇到周末会跳过。

## 导入完整计划

1. 点击“从 AI 导入计划”，粘贴符合 [TW_PLAN_V1](TW_PLAN_V1.md) 的 JSON 或单个 json 代码块。
2. 点击“解析与校验”，查看计划名称、目标、执行天数、任务数和已知/未知时长。
3. 选择开始日期、执行星期及可选的每日任务/预计分钟上限。快捷选择只设置星期勾选，实际依据始终是勾选的星期。
4. 查看各 Day 的实际日期、任务和结束日期。上限包含已有任务，未知预计时长明确提示无法完整判断。调整规则或勾选明确保持安排。
5. 确认导入整个计划。成功后点击“完成”查看任务。确认前不写入数据；成功后是一次追加保存。相同计划再次导入需明确确认。

“导入今日计划”继续支持旧版单日 JSON，不支持多日调度。两者入口分别保留。昨日未完成任务仍需手动选择加入今日；整个计划不会自动顺延。

已导入计划可在设置底部查看名称和日期范围，点击名称跳到开始日；本版不加入额外目标管理界面。

## 个性化与备份

在设置 → 外观与个性化中选择短句轮播/固定句，以及两张卡片各自的默认、图片或隐藏。图片预览裁剪后确认保存，默认不叠加文字。详见 [本地图片说明](PERSONALIZATION.md)。

“导出全部数据”包含计划、任务、路线、刷题、图片和设置。恢复仍先预览再确认覆盖，并保留恢复前快照；普通计划导入始终追加，不会执行备份恢复的覆盖操作。旧版不含计划和图片的备份继续可用。

## 启动与 PWA

双击项目里的 `启动 Today Work.cmd`，保持窗口运行，浏览器打开 http://127.0.0.1:8765/ 。需要本机已安装 Node.js，无需安装 npm 包；这个静态服务只监听本机，不含业务后端。

在设置 → 安装与离线使用中等待“离线资源已就绪”；Edge/Chrome 满足条件时显示“安装 Today Work”，也可使用浏览器地址栏安装入口。安装为独立窗口由 manifest 声明。首次资源缓存成功后，任务、完整计划导入和图片可离线使用。

发现新版本会提示关闭所有 Today Work 标签页/独立窗口后重新打开，避免在编辑中强制换版本。本轮缓存版本 `v2.1.2`。所有资源使用相对路径，可放入 GitHub Pages 子目录；本轮没有发布。

也可双击 `index.html` 使用核心任务和计划功能；file:// 不能安装 PWA，界面会提示限制。文件地址、localhost 网址、不同端口是不同存储空间，换入口不会自动迁移记录。请保持原来的使用入口；如需更换，先在原入口导出完整 JSON 再恢复。
