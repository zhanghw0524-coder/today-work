# 轻量音效（2.4）

入口：设置 → 轻量音效。默认关闭、默认音量 25%，可开关、调整音量、分别试听。设置保存在 `settings.sound = { enabled, volume }`（音量 0–1），随完整备份导出；旧数据和旧备份缺少该字段时仍默认关闭。

仅两种声音，由本机 Web Audio API 生成，不下载音频、不调用 API：

- 成功保存一次手动完成：约 0.2 秒的轻短音。
- 当天有任务，从未全部完成变为全部完成：约 0.5 秒的短上行和声，仅播放这一种。

完成判断位于勾选事件成功保存之后，要求可信手动事件、原任务未完成、勾选为完成、任务总数不变且完成数恰好增加一项。全部完成额外要求所选日期为今天。首次打开、刷新、切换日期、导入、备份恢复、删除、撤销删除、取消完成、普通渲染都不触发。删除最后一项未完成任务不会被视为完成全部。

音频上下文按首次用户交互创建并复用，快速操作使之前的声音渐弱并停止，不不断叠加。等待恢复上下文时只保留最后一次请求。音量为零、默认关闭、浏览器限制、设备错误均不会影响任务保存；播放失败不反复弹窗。试听是明确的用户操作，即使正式反馈开关关闭也可试听。

浏览器、系统静音和输出设备决定最终能否听到；不保证后台、锁屏播放。本项目不提供背景音乐、番茄钟、计时、结束铃声或专注统计。

自动验证见 `tests/sounds.test.cjs`；实际浏览器通过按钮试听、可信 checkbox 点击验证触发，并使用同一合成函数渲染 WAV 样本。当前验收工具无法回传听觉感受，因此**尚未由人耳确认舒适度**，详见 [2.4 验收](../tests/QA-2.4.md)。
