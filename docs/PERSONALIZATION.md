# 首页外观与本地图片

入口：设置 → 外观与个性化。六条内置短句每 8 秒切换，仅修改每日任务页标题；其他页面标题保持原功能。可关闭轮播并选择固定短句。系统 `prefers-reduced-motion: reduce` 时固定显示选择的短句，不播放切换动画。页面隐藏时不轮播。

左侧励志卡片、右侧日历下方卡片分别支持默认、自定义图片、隐藏。选择图片后先压缩，在独立弹窗中调整水平/垂直裁剪位置与是否叠加原文案；确认前不改变已保存设置。图片保持比例，以 `object-fit: cover` 裁切。左侧比例 3:4，右侧 5:4。手机端隐藏侧栏卡片，先展示任务，再显示日历与右侧卡片。

只接受 JPG、PNG、WebP，原文件最大 15MiB、4000 万像素。最长边缩至 1600px，优先 WebP 多档质量，必要时 JPEG；编码后的 data URL 最大 700000 字符（图片数据约 512KiB）。不上传任何图片。

设置保存在原有 localStorage 的 `settings.personalization`；图片保存在 IndexedDB `today-work-images` / `images`。保存图片先完成 IndexedDB 写入，再提交设置；设置保存失败会撤销本次新增图片，原卡片及任务不变。读取图片失败在设置中提示并回退到默认卡片展示，可重试或重新选择。

完整 JSON 备份继续使用 `backupVersion: 1`，新增可选 `imageAssets`，仅导出正在使用的图片；计划记录和任务来源关联也在 `data` 内。旧备份没有这些字段时仍可恢复。缺少已关联图片的备份、无效图片类型或尺寸会被拒绝，不生成看似成功的不完整恢复。恢复时先使用新 ID 写入图片，再由原有单次 localStorage 保存机制提交数据；失败撤销暂存图片。恢复前快照引用的旧图片会保留，可通过“导出恢复前备份”一起导出。

更换/恢复默认不会自动删除历史图片，以免其他窗口、恢复前快照或正在导出的备份失去图片。这些图片占用本地 IndexedDB 空间；本版尚无历史图片空间管理入口。完整备份不携带未使用图片。浏览器存储仍可能被用户清理或浏览器回收，应定期导出完整备份。

文件直开时 IndexedDB 支持及存储范围由浏览器决定；不可用会显示保存失败，原任务仍使用原来的 localStorage。PWA 必须在 localhost 或 HTTPS 使用。
