# 首页外观与本地图片（2.4）

入口：设置 → 外观与个性化。首页以日期、任务、完成进度和添加按钮为主，统计集中在“进度”。手机主导航为“今天 / 计划 / 进度 / 设置”；路线、刷题、历史和旧版单日导入仍可从“计划 → 已有计划与更多工具”进入。

六条内置短句约每 15 秒切换，只影响首页标题。首页提供暂停、继续和关闭入口，状态与当前短句会保存；设置可选择固定短句。页面不可见时跳过切换，系统 `prefers-reduced-motion: reduce` 时不轮播、不播放切换动画。标题预留两行高度，切换不移焦点。

## 两张卡片独立设置

左侧励志卡片、右侧日历下方卡片分别支持默认、自定义图片、隐藏。首次仍显示原有默认设计。手机默认收起两张装饰卡片；开启“在手机显示装饰卡片”后，位于任务之后，不挤占任务上方空间。日历和最近记录在手机默认折叠。

选择图片后在本机压缩，弹窗可调整水平/垂直裁切位置、选择叠加原文案。确认前不改变已保存卡片；取消可直接退出。图片以 `object-fit: cover` 保持比例裁切，左侧比例 3:4，右侧 5:4。隐藏仍保留图片和位置，可切回“自定义图片”；“恢复默认”仅重置对应一张卡片。

只接受 JPG、PNG、WebP，原文件最大 15MiB、4000 万像素。最长边缩至 1600px，优先 WebP 多档质量，必要时 JPEG；编码后的 data URL 最大 700000 字符（实际图片数据约 512KiB）。格式、尺寸、读取、压缩或保存失败会显示原因。不上传图片。

## 保存、清理与兼容

设置保存在原 localStorage 的 `settings.personalization`，新增可选 `paused`、`mobileCards`（默认 false）；图片仍保存在 IndexedDB `today-work-images` / `images`，不把图片放进任务的 localStorage。

保存先写入新的不可变图片 ID，再通过原有单次保存提交设置。图片写入或设置提交失败，原卡片及任务保持不变，并尽量回滚暂存图片。预览期间另一窗口修改同一张卡片时，拒绝旧预览覆盖新设置。支持 Web Locks 的浏览器会串行处理图片保存、备份和恢复；其他浏览器使用本窗口队列。

替换或恢复默认后，清理已释放且没有引用的图片。保留另一张卡片、隐藏卡片、恢复前/迁移/恢复快照引用的图片；无法读取快照时暂缓清理。新版本遗留的暂存图片超过五分钟可在下次卡片保存时回收；无法确认来源的旧版孤立图片不会批量清除。清理失败不会撤销已经成功保存的卡片，设置中会提示。不存在自动删除用户任务的逻辑。

完整 JSON 备份继续使用 `backupVersion: 1`，可选 `imageAssets` 包含当前两张卡片引用的图片，**包括已隐藏的图片**；不携带未使用图片。计划、任务来源、音效与外观设置均在 `data` 内。旧备份没有新增字段仍可恢复。缺少关联图片、无效类型或尺寸会拒绝恢复；不生成不完整备份。恢复先暂存新 ID 图片，再提交正式数据，恢复前快照引用的旧图片会保留以供导出。

刷新及首次缓存成功后的离线重开可继续读取本地图片和设置。浏览器仍可能因用户清理、存储权限或容量回收而失去数据，请定期导出完整备份。

`file://` 下 IndexedDB 支持和数据范围由浏览器决定；不可用会显示保存失败，任务仍沿用原 localStorage。安装和离线缓存需要 localhost 或 HTTPS。不同端口、域名、浏览器是独立的数据空间。
