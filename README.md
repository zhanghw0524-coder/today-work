# Today Work

**把计划，变成今天要做的事。**  
Turn plans into daily action.

Today Work 是一个轻量的学习、成长与任务管理工具，可用于学习、考试、工作、科研、阅读、健身等场景。

无需注册，数据保存在自己的浏览器中。

👉 **[打开 Today Work](https://zhanghw0524-coder.github.io/today-work/)**

## 核心功能

- **每日任务**：按日期、分类管理任务，支持完成勾选、优先级、预计时间与实际用时。
- **计划导入**：将外部 AI 生成的结构化计划导入，预览后生成每日任务。
- **执行日设置**：选择开始日期和每周执行星期，自动跳过未选择的日期。
- **学习路线**：创建自己的路线、阶段与知识点，记录完成进度。
- **记录与统计**：查看历史任务、完成率、学习日历与连续打卡。
- **刷题记录**：记录题目、熟练度和复习情况，按需使用。
- **个性化**：深浅主题、顶部短句、左右卡片自定义图片。
- **备份恢复**：导出与导入 JSON，迁移或备份个人数据。
- **PWA**：支持安装为独立应用，资源缓存完成后可离线使用。

## AI 负责规划，Today Work 负责执行

Today Work **不调用任何 AI API**。你可以自行选择 ChatGPT、Claude、DeepSeek、豆包或其他 AI。

使用流程：

1. 在 Today Work 点击“让 AI 帮我制定计划”。
2. 填写目标、执行天数、每天可投入时间及其他要求。
3. 复制生成的提示词，发送给你喜欢的 AI。
4. 将 AI 返回的 `TW_PLAN_V1` JSON 粘贴到“从 AI 导入计划”。
5. 设置开始日期、执行星期及每日上限。
6. 检查日期与任务预览，确认后导入。

AI 输出 Day 1、Day 2 等执行日，Today Work 将它们映射到实际日期。

当前每日任务数和时长上限用于提示，不自动拆分任务或重排整个计划。未完成任务由用户选择是否加入今日。

## 安装到桌面

使用支持 PWA 的浏览器打开网站：

1. 在设置中等待“离线资源已就绪”。
2. 点击“安装 Today Work”，或使用浏览器提供的安装入口。
3. 安装后，通过桌面或开始菜单图标打开。

Android 可使用支持安装的浏览器添加到主屏幕。安装入口与操作方式因浏览器而异。

首次访问需要联网；资源成功缓存后，核心功能可离线使用。

## 数据与隐私

- 任务、记录和设置保存在当前浏览器中，图片保存在本地 IndexedDB 中。
- 应用不将个人任务、计划或上传的图片发送到服务器。
- 网站托管服务仍可能记录常规访问日志。
- 当前不提供账号或跨设备自动同步。
- 不同设备、浏览器及网站地址使用独立的数据空间。
- 清除网站数据、使用无痕模式或更换设备，可能导致原有记录不可用，请定期导出备份。

从本地文件版或本地网址迁移时：

**旧入口导出全部数据 → 新网址导入备份 → 检查恢复结果。**

备份恢复会覆盖当前数据，请先核对预览。普通计划导入则追加任务。

## 技术与项目方向

采用 HTML、CSS、JavaScript、localStorage、IndexedDB 和 Service Worker。

保持纯前端，不需要业务后端、数据库服务器或 AI API。在线使用者无需安装 Node.js。

Today Work 专注于：

**目标 → 计划 → 每日行动 → 记录与调整**

让计划真正执行下去。

## 本地开发与同步

仓库根目录就是应用目录，运行 `node server.cjs` 后打开 http://127.0.0.1:8765/；也可以双击 `启动 Today Work.cmd`。所有功能保持纯前端，Node 仅用于本地静态文件服务。

自动检查：

```text
node --test tests/core.test.cjs tests/plans.test.cjs tests/assets.test.cjs tests/deletions.test.cjs tests/pwa.test.cjs
```

后续修改使用普通 Git 提交和推送：

```text
git status
git fetch origin
git diff
git add <本次需要提交的文件>
git commit -m "说明本次修改"
git push origin main
```

远程有新提交时，先检查并合并后再推送；不要强制推送。`.gitignore` 排除本地备份、个人数据、测试导出、截图、依赖和密钥文件。提交前仍需检查 `git diff --cached`，不要将个人数据写入源码或文档。

当前保留根目录静态站点结构和相对资源路径，兼容 GitHub Pages 的仓库子目录；本次不更改仓库 Pages 设置。浏览器个人数据不随 Git 同步，本地网址与线上网址之间迁移仍须手动导出、恢复备份。
